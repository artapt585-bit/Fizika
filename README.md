
Этот репозиторий создан для индивидуального проекта по физике на тему «Физика в цифрах». 
Внутри приложения будет возможность проводить простые эксперименты и получать обратную связь.

## Как запустить
Если захотите протестировать
1. Скопируйте репозиторий
```bash
  git clone https://github.com/artapt585-bit/Fizika
```
2. Загрузите необходимые библиотеки
```bash
  pip install -r requirements.txt
```
3. Запустите файл main.py через python
```bash
 python main.py
```
